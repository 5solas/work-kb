# 작업: 태그 (T1)

입력은 daily `## 기록`의 줄 목록이다. 줄마다 앞에 `[L1]` 같은 줄 id와 날짜가 붙어 있다.
줄마다 아래 고정 태그 10개 중 가장 알맞은 것 하나를 고른다.

고정 태그: 회의, 결정, 요청, 이슈, 학습, 아이디어, 개인, 참고, 일정, 리뷰

규칙
- 목록에 없는 태그를 만들지 않는다. 태그 글자를 바꾸지 않는다(`#`, 공백, 영어 금지).
- 입력에 있는 줄 id만 쓴다. 모든 줄 id에 태그를 하나씩 단다.
- 줄 내용을 고쳐 쓰거나 설명을 덧붙이지 않는다.
- 애매하면 `참고`를 쓴다. `개인:`으로 시작하는 줄은 `개인`이다.

출력: JSON 객체 하나만. 코드 블록이나 다른 글 없이 `{`로 시작해 `}`로 끝낸다.

{"tags": {"L1": "회의", "L2": "결정"}}
