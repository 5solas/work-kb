# 작업: 결정과 할 일 (T2)

입력은 하루치 기록이다.
- `## 기록`: 그날 daily의 줄. 앞에 `[L1]` 같은 줄 id가 있다.
- `## 이미지 추출문`: 그날 이미지에서 읽은 글. 줄 id는 `[X1]` 꼴이다.
- `## 관련 Jira 일감`: 기록에 나온 일감의 캐시 요약(참고용, 출처로 쓰지 않는다).

할 일
1. 결정: 정해진 것(합의, 방침, 선택)만 뽑는다. 논의 중이거나 추측은 결정이 아니다.
2. 할 일: 누군가 해야 하는 일로 적힌 것만 뽑는다. `[ ]`·`[x]` 체크박스 줄은 할 일로 뽑지 않는다.
3. `(이미 반영)` 표시가 있는 줄에서는 아무것도 뽑지 않는다(맥락으로만 읽는다).

규칙
- `source_line`에는 근거가 된 줄의 id 하나를 그대로 쓴다(`L3`, `X1`). 입력에 없는 id는 쓰지 않는다.
- `related`에는 줄에 나온 Jira 키(`KB-12`)와 사람(`@김철수`)만 넣는다. 입력의 프로젝트 키 밖의 키는 넣지 않는다.
- `title`은 한 줄, 30자 안팎. `content`·`rationale`은 짧은 한 문장. 근거가 줄에 없으면 `rationale`은 빈 문자열.
- 입력에 없는 사실을 지어내지 않는다. 사람의 개인 정보는 쓰지 않는다.
- 뽑을 것이 없으면 빈 목록을 쓴다.

출력: JSON 객체 하나만. 코드 블록이나 다른 글 없이 `{`로 시작해 `}`로 끝낸다.

{"decisions": [{"title": "캐시 updated 시각은 UTC로 저장", "content": "jira 캐시의 updated 값을 UTC로 저장한다.", "rationale": "시간대 혼동을 막는다.", "related": ["KB-12", "@김철수"], "source_line": "L1"}], "actions": [{"text": "배포 체크리스트 초안 작성", "related": ["OPS-3"], "source_line": "L2"}]}
