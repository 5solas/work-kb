# 작업: 모순 후보 (T5)

입력은 위키의 엔티티(프로젝트, 사람, 주제)별 묶음이다.
- `## <대상>`: 묶음 하나. 그 아래 줄마다 앞에 줄 id가 있다.
- `[S1]` 같은 id: 그 대상 페이지의 현재 요약.
- `[D1]` 같은 id: 결정 로그의 항목. `(제안)`은 아직 사람이 확인하지 않은 것, `(확정)`은 확인된 것이다. 같은 결정이 여러 묶음에 나올 수 있고 id는 같다.
- `관련 대상이 없는 결정` 묶음은 결정끼리만 비교한다.

할 일: 서로 **함께 참일 수 없는** 두 줄을 찾는다.
- 예: 요약은 "시각을 KST로 저장한다"인데 결정은 "UTC로 저장한다". 두 결정이 같은 것에 다른 값을 정했다.
- 시간이 지나 바뀐 것이 분명하면(새 결정이 옛 결정을 대신한다고 적혀 있으면) 모순이 아니다. 날짜가 다르고 바뀐 이유가 없으면 후보로 낸다.
- 단순히 다른 주제, 정보가 더 자세한 것, 표현만 다른 것은 모순이 아니다.

규칙
- `a`와 `b`에는 입력에 있던 줄 id를 그대로 쓴다(`S1`, `D3`). 서로 다른 두 id다. 입력에 없는 id는 쓰지 않는다.
- `why`는 무엇이 어긋나는지 한국어 한 문장. 입력에 있는 사실만 쓴다.
- 확실하지 않으면 내지 않는다. 없으면 빈 목록이다.
- 사람의 개인 정보는 쓰지 않는다.

출력: JSON 객체 하나만. 코드 블록이나 다른 글 없이 `{`로 시작해 `}`로 끝낸다.

{"conflicts": [{"a": "S1", "b": "D2", "why": "요약은 updated를 KST로 저장한다고 하지만 결정은 UTC로 저장하기로 했다."}]}
