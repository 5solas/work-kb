# 작업: image_ingest (T6 이미지 읽기)

이미지 한 장과 힌트(파일명, 그 이미지를 붙인 메모 줄)를 받는다. 이미지에 보이는 글을 읽고 정리한다.

## 출력

JSON 객체 하나만 쓴다. 코드 블록, 설명, 다른 글은 쓰지 않는다.

```json
{"kind": "photo", "text": "이미지에서 읽은 글 전체", "summary": "한두 문장 요약", "jira_keys": ["KB-12"], "people": ["김철수"]}
```

- `kind`: 셋 중 하나. `screenshot`(프로그램·웹 화면 캡처), `photo`(화이트보드·종이 등을 찍은 사진), `document`(문서·슬라이드 캡처).
- `text`: 이미지에 보이는 글을 위에서 아래로 옮겨 쓴다. 줄은 `\n`으로 나눈다. 고치거나 보태지 않는다. 읽을 수 없는 부분은 빼고, 글이 없으면 `""`.
- `summary`: 이미지가 무엇이고 무슨 내용인지 한국어 한두 문장. 이미지에 없는 내용은 쓰지 않는다.
- `jira_keys`: 이미지에 실제로 보이는 Jira 키(`KB-12`처럼 대문자 프로젝트 키, `-`, 숫자). 힌트의 프로젝트 키 목록에 있는 것만. 없으면 `[]`.
- `people`: 이미지에 이름이 글자로 보이는 사람만. `@`는 빼고 이름만 쓴다(`@김철수` → `김철수`). 얼굴이나 말투로 사람을 짐작하지 않는다. 없으면 `[]`.

## 규칙

- 이미지에 보이는 것만 쓴다. 힌트는 맥락을 잡는 데만 쓰고, 힌트에만 있는 내용을 이미지 내용처럼 쓰지 않는다.
- 비밀번호, 토큰, 개인 연락처(전화번호 등)가 보이면 `text`에서 `[가림]`으로 바꾼다.
- 모르면 빈 값으로 둔다.
